# Appendix A: The Field Cards

Thirty-three cards, one per chapter, in chapter order.

Each card is its chapter compressed to what fits in front of someone who has
four minutes before a call. The trigger, the words, what to listen for, the
metric, the failure mode, and the sentence that recovers it.

## How to use them

Print this appendix, cut on the borders, and put one card on a desk. Not
thirty-three. One.

The card that belongs on a desk is the one for the behavior that floor is
currently worst at, and Chapter 33's scorecard tells you which that is. A rep
with the right card in front of them executes better than a rep who read the
chapter twice, because the card is available at the moment of use and the
chapter is not.

Laminate them if they are going on a sales floor. They get handled.

**The one card everyone should carry first:** Card 08, Tactical Silence.
Concessions made after the other side goes quiet is the largest single leak on
most untrained floors, it is countable from any recording, and it is fixable
in about forty minutes of drilling. Start there and earn the right to hand out
the other thirty-two.

## Part 0 · The Standard


**Card 01 · The Negotiation Is Already Running**

```
┌────────────────────────────────────────────────────────┐
│  ALREADY RUNNING                    Part 0 · STANDARD  │
├────────────────────────────────────────────────────────┤
│  It started before you. Find out where it stands.      │
│                                                        │
│  ASSUME        Positions were formed in rooms you      │
│                weren't in, by people you can't name.   │
│                                                        │
│  EARLY JOB     Locate. Not persuade. Not present.      │
│                                                        │
│  ASK           "When did this first come up?"          │
│                "Who else has been part of this?"       │
│                "What's the feeling internally?"        │
│                "If this stalled, what happens instead?"│
│                                                        │
│  LISTEN FOR    A date        → work backwards from it  │
│                A new name    → most important person   │
│                "Just gathering info"  → position exists│
│                A long pause  → don't fill it           │
│                                                        │
│  SCORED        3+ named participants · start date      │
│                precedes first contact · alternative    │
│                documented · talk time under 40%        │
│                                                        │
│  FAILS WHEN    You treat the early phase as neutral.   │
│                It is never neutral.                    │
│  RECOVER       "I threw a number at you earlier I      │
│                hadn't thought through. Where did       │
│                that land on your end?"                 │
└────────────────────────────────────────────────────────┘
```

```

├────────────────────────────────────────────────────────┤

│                                                        │
│  1 READ      Diagnose. Emotion + decision structure.   │
│    CLEARED   Name 1 specific emotion + 3 participants. │
│                                                        │

│                                                        │

│                                                        │

│    CLEARED   "That's right."  (not "you're right")     │
│                                                        │

│              Disarm present · Steer talk time <40% ·   │
│              Zero concessions after silence            │
│                                                        │
│  FAILS WHEN  You jump to Steer because it's the stage  │
│              that feels like negotiating.              │
│  RECOVER     "I've been throwing solutions at this and │
│              I haven't understood where you're sitting.│
│              What's the hardest part of this for you?" │

```

## Part I · Read


**Card 04 · Diagnose Before You Ask**

```
┌─────────────────────────────────────────────────────────┐
│  DIAGNOSE BEFORE YOU ASK             Part I · READ      │
├─────────────────────────────────────────────────────────┤
│  Output: you can state their position better than they  │
│  did. Not kindly. Accurately.                           │
│                                                         │
│  ENCOURAGERS  "Mm-hmm." · "Go on." · "And then what?"   │
│               "Say more about that." · "Take your time."│
│               The rule is they END. Then you stop.      │
│                                                         │
│  LISTEN FOR   "It sounds like the surface ask isn't     │
│                the real ask."                           │
│               "Is this a won't, or is it a can't?"      │
│               "What are you actually protecting here?"  │
│               "If I only understood one thing about     │
│                this, what should it be?"                │
│                                                         │
│  CLEAN LANG   Repeat THEIR word. Make it smaller.       │
│               "Complicated", complicated how?           │
│               "Expensive", compared to what?            │
│               "Risky", risky how, specifically?         │
│               Never swap in your own word.              │
│                                                         │
│  SCORED       Talk time <30% · half the fuzzy words     │
│               made specific · playback needs no         │
│               amending · zero solutions offered         │
│                                                         │
│  FAILS WHEN   You listen in order to reply. They can    │
│               hear it. They start giving you the        │
│               short version of everything.              │
│  RECOVER      "I got ahead of you there. Go back,       │
│               you were saying something about ___."     │
└─────────────────────────────────────────────────────────┘
```


**Card 05 · The Emotion Vocabulary**

```
┌────────────────────────────────────────────────────────┐
│  THE EMOTION VOCABULARY              Part I · READ     │
├────────────────────────────────────────────────────────┤
│  Get the STATE right before you get specific.          │
│                                                        │
│  TORN        Two good reasons, opposite directions.    │
│              → Name the tension, don't argue a side.   │
│              "You're not indecisive, you're being      │
│               honest about the tradeoffs."             │
│                                                        │
│  READY       Thinking's done. Waiting on logistics.    │
│              → Stop selling. Start scheduling.         │
│              "Let's put a real date on it. Not soon,   │
│               not this week. A date."                  │
│                                                        │
│  NOT YET     No problem, so no negotiation.            │
│              → Find the future where they'd have one.  │
│              "Is this a someday thing, or a            │
│               never-really thing?"                     │
│                                                        │
│  SOMATIC     Say what you SAW, never what it means.    │
│              "Your jaw just tightened. That's not      │
│               agreement."   Max one per ten minutes.   │
│                                                        │
│  SCORED      Specific not generic ("frustrated" = 0) · │
│              evidence on every read · state called     │
│              right · Ready spotted before the last call│
│                                                        │
│  FAILS WHEN  Pressure collapses you back to the same   │
│              three adjectives.                         │
│  RECOVER     "Something's landing harder than the rest │
│              and I don't want to guess. What is it?"   │
└────────────────────────────────────────────────────────┘
```


**Card 06 · Labeling**

```
┌────────────────────────────────────────────────────────┐
│  LABELING                           Part I · READ      │
├────────────────────────────────────────────────────────┤
│  Name their emotion out loud. Then stop.               │
│                                                        │
│  OPENERS      "It seems like…"  "It sounds like…"      │
│               "It looks like…"                         │
│                                                        │
│  RULES        Points at them. Never starts with "I."   │
│               No question mark. Nothing follows it.    │
│                                                        │
│  LISTEN FOR   "That's right."     → landed, move on    │
│               A correction        → better; take it    │
│               "You're right."     → appeasement; retry │
│               Silence             → wait four seconds  │
│                                                        │
│  SCORED       Specific, not generic · Landing rate >50%│
│               Before the first ask · Clean delivery    │
│                                                        │
│  FAILS WHEN   You solve before you diagnose.           │
│  RECOVER      "I jumped to fixing that before I under- │
│               stood it. What's the hardest part here?" │
└────────────────────────────────────────────────────────┘
```


**Card 07 · Mirroring**

```
┌─────────────────────────────────────────────────────────┐
│  MIRRORING                           Part I · READ      │
├─────────────────────────────────────────────────────────┤
│  Their last 1-3 words. Upward inflection. Then nothing. │
│                                                         │
│  DO           "A budget issue this quarter?"            │
│               "Not interested?"                         │
│               "Impossible?"                             │
│               "Sixty thousand?"                         │
│                                                         │
│  RULES        Up, not flat, flat reads as disagreement. │
│               Nothing follows it. Not one word.         │
│               Mirror the number, never your reaction.   │
│               Best target = heaviest word, not last.    │
│                                                         │
│  DON'T        Twice in a row. Direct factual questions. │
│               Anything genuinely heavy (use a label).   │
│                                                         │
│  LISTEN FOR   They keep going        → the point        │
│               Absolute → conditional → the gold         │
│               They self-correct      → new information  │
│               They laugh             → say "fair enough"│
│                                                         │
│  SCORED       Clean delivery · elaboration rate >70% ·  │
│               max 1 per 2 min · zero reaction leakage   │
│                                                         │
│  FAILS WHEN   It doesn't land so you do it again.       │
│  RECOVER      Drop the tool. "Let me be more direct,    │
│               what's actually driving that number?"     │
└─────────────────────────────────────────────────────────┘
```


**Card 08 · Tactical Silence**

```
┌────────────────────────────────────────────────────────┐
│  TACTICAL SILENCE                    Part I · READ     │
├────────────────────────────────────────────────────────┤
│  Silence isn't empty. It's still your turn. You just   │
│  haven't used it yet.                                  │
│                                                        │
│  USE IT      After a label. After your number.         │
│              After a calibrated question.              │
│              When they've gone quiet and are working.  │
│                                                        │
│  DON'T       As punishment. After a direct question.   │
│              On a bad video connection.                │
│                                                        │
│  THE HOLD    Six seconds. Count them. Breathe out.     │
│              Don't summarize what you just said.       │
│              It already landed.                        │
│                                                        │
│  THE VOICE   Drop pitch. Slow down. Trail sentences    │
│              DOWN, not up.                             │
│              Say the hard part in the same tone as     │
│              the easy part.                            │
│              Match energy, not volume.                 │
│              Rushing a number makes it negotiable.     │
│                                                        │
│  SCORED      6-second hold · they speak first >50% ·   │
│              ZERO concessions after silence ·          │
│              zero sentences after your own price       │
│                                                        │
│  FAILS WHEN  You read quiet as displeasure and improve │
│              an offer nobody objected to.              │
│  RECOVER     Make it a trade, not a gift: "I meant it, │
│              if the start date moves to the first."    │
└────────────────────────────────────────────────────────┘
```


**Card 09 · Reading the Decision Structure**

```
┌────────────────────────────────────────────────────────┐
│  DECISION STRUCTURE                  Part I · READ     │
├────────────────────────────────────────────────────────┤
│  The person in front of you is usually not the person  │
│  you're negotiating with.                              │
│                                                        │
│  PRONOUNS    "I"    → real ownership                   │
│              "We"   → a committee exists. Find it.     │
│              "They" → authority is elsewhere           │
│              A name → gold. Write it down.             │
│              A switch mid-sentence → their real limit  │
│                                                        │
│  INFO LABEL  "It seems like there's a detail nobody's  │
│               said out loud yet."                      │
│              "It looks like I need help with this."    │
│                                                        │
│  POWER LABEL "It sounds like whoever's really in charge│
│               isn't even in this room."                │
│              "It seems like you'd need permission just │
│               to say yes to this."                     │
│              Flat and warm. Never sharp.               │
│              Confirm OR pushback. Both are wins.       │
│                                                        │
│  MISLABEL    "It looks like this decision is entirely  │
│               yours to make."                          │
│              Must be PLAUSIBLE. Aim just past what     │
│              you believe.                              │
│                                                        │
│  SCORED      3+ named participants · signer confirmed  │
│              not assumed · >50% facts on the map ·     │
│              1+ structure probe per discovery call     │
│                                                        │
│  FAILS WHEN  You believe the enthusiastic contact.     │
│  RECOVER     "You've been carrying this internally and │
│              I don't want that to fall on you alone.   │
│              Who else should be in the next one?"      │
└────────────────────────────────────────────────────────┘
```


## Part II · Disarm


**Card 10 · The Accusation Audit**

```
┌─────────────────────────────────────────────────────────┐
│  THE ACCUSATION AUDIT               Part II · DISARM    │
├─────────────────────────────────────────────────────────┤
│  Say the worst thing they think, before they can.       │
│  An objection you've already voiced is spent.           │
│                                                         │
│  BUILD IT    "You probably think…"                      │
│              "It might seem like…"                      │
│              "It probably looks like…"                  │
│                                                         │
│  MOTIVE      "You probably think I'm just trying to     │
│               squeeze you here."                        │
│  CREDIBILITY "You might be thinking I don't actually    │
│               know what I'm talking about."             │
│  AFTER       "You might be thinking I'll disappear the  │
│               second this is signed."                   │
│                                                         │
│  RULES       Rank by DAMAGE, not likelihood.            │
│              Open with the top two.                     │
│              Say it and STOP. No "but." No defense.     │
│              Flat tone, same as the easy part.          │
│                                                         │
│  LISTEN FOR  A laugh          → pressure released       │
│              "Yeah, honestly" → the real objection      │
│              They upgrade it  → better than being right │
│              They defend YOU  → now they're consistent  │
│                                                         │
│  SCORED      Present before the ask · top-two severity ·│
│              ZERO defense sentences · room cooled       │
│                                                         │
│  FAILS WHEN  You audit the safe one and leave the real  │
│              objection sitting there.                   │
│  RECOVER     "That wasn't the real one. The real one    │
│              is that you think the number is high and   │
│              you've been burned before."                │
└─────────────────────────────────────────────────────────┘
```


**Card 11 · The Negative Label**

```
┌────────────────────────────────────────────────────────┐
│  THE NEGATIVE LABEL                 Part II · DISARM   │
├────────────────────────────────────────────────────────┤
│  Name the bad thing that's in the room and unsaid.     │
│  Audit = pre-emptive, about you.                       │
│  Negative label = responsive, about whatever it is.    │
│                                                        │
│  AT YOU      "Sounds like you don't trust me."         │
│              "It probably seems like we're being       │
│               selfish."                                │
│                                                        │
│  AT THE ROOM "It feels like there's an obstacle here." │
│              "It sounds like there's a version of this │
│               you're not saying out loud."             │
│                                                        │
│  AT THEM     "It sounds like you have a reason to say  │
│               that."                                   │
│              "Seems like you're under some pressure."  │
│              "It sounds like you're in a tough spot."  │
│                                                        │
│  RULES       Flat and warm, never hot.                 │
│              One, then silence. Never two in a row.    │
│              No hedging. Two qualifiers kills it.      │
│                                                        │
│  LISTEN FOR  Denial WITH detail → the detail is the win│
│              "How did you know?" → it landed           │
│              They name a bigger one → better           │
│              Pause + register change → it landed       │
│                                                        │
│  SCORED      Concealed objection said out loud · flat  │
│              delivery · silence held · one per exchange│
│                                                        │
│  FAILS WHEN  You sand the edges off and nothing lands. │
│  RECOVER     "Let me try that again without the        │
│              hedging. It seems like something is       │
│              holding you back."                        │
└────────────────────────────────────────────────────────┘
```


**Card 12 · The Power of "No"**

```
┌──────────────────────────────────────────────────────────┐
│  THE POWER OF "NO"                  Part II · DISARM     │
├──────────────────────────────────────────────────────────┤
│  "No" is the beginning. Go and get it on purpose.        │
│  People agree to things they're free to refuse.          │
│                                                          │
│  INVERT      "Do you have a few minutes?"                │
│                → "Is this a bad time?"                   │
│              "Are you still interested?"                 │
│                → "Have you given up on this?"            │
│              "Am I understanding correctly?"             │
│                → "Is my read on this wrong?"             │
│                                                          │
│  SURFACE     "Is something being left unsaid?"           │
│              "Would you be against being honest here?"   │
│              "Are you against putting everything on      │
│               the table?"                                │
│                                                          │
│  STALLS      "Should I just stop trying?"                │
│              "Is this hopeless, or am I missing          │
│               something?"                                │
│                                                          │
│  CHECK SELF  "Have I misunderstood what you need?"       │
│              "Am I talking to the wrong person?"         │
│                                                          │
│  RULES       Only ask what you can survive a "yes" to.   │
│              Never re-ask the same one.                  │
│              Ask it, then SILENCE. No "because." No "or."│
│                                                          │
│  SCORED      Orientation ratio · early no obtained ·     │
│              all asks survivable · zero re-asks ·        │
│              30-day stalls converted either way          │
│                                                          │
│  FAILS WHEN  You fear the no you asked for and hand      │
│              them three exits.                           │
│  RECOVER     "Sorry. I'll just ask it straight.          │
│              Is this a bad time?"                        │
└──────────────────────────────────────────────────────────┘
```


**Card 13 · Validation**

```
┌──────────────────────────────────────────────────────────┐
│  VALIDATION                         Part II · DISARM     │
├──────────────────────────────────────────────────────────┤
│  Their position makes sense from where they stand.       │
│  That is NOT agreement. You concede nothing.             │
│                                                          │
│  EMPATHY     "That's not an overreaction. That's what    │
│               this situation calls for."                 │
│              "Anyone in your position would be asking    │
│               the same questions right now."             │
│              "It makes sense you'd want more than my     │
│               word on this."                             │
│                                                          │
│  POSITIVE    "It seems like you'd like to make this      │
│               work, but there are things in the way."    │
│              "You seem like the type of person who       │
│               prides themselves on how they do business."│
│              Must be TRUE. Untrue = flattery = costly.   │
│                                                          │
│  TRUST       "At what point did trust break down here?"  │
│              "What's the smallest thing I could do right │
│               now that would mean something?"            │
│              "What's the fastest way I could lose        │
│               whatever trust we've built so far?"        │
│                                                          │
│  RULES       Never follow with "but."                    │
│              Validate, then be QUIET.                    │
│              Under 90 seconds, it's a bridge, not a      │
│              destination.                                │
│                                                          │
│  SCORED      Validated + terms unmoved · zero "but" ·    │
│              label passes the truth test · defending     │
│              stopped                                     │
│                                                          │
│  FAILS WHEN  You validate, then argue in the same        │
│              breath. Now they know what it precedes.     │
│  RECOVER     "I did that badly. I validated you and      │
│              then argued with you. Let me leave the      │
│              first part where it is."                    │
└──────────────────────────────────────────────────────────┘
```


**Card 14 · The Discipline of Not Defending**

```
┌────────────────────────────────────────────────────────┐
│  THE ATTACK DECODER                  Part II · DISARM  │
├────────────────────────────────────────────────────────┤
│  An attack is one of three things. Decode before       │
│  you respond. Never defend first.                      │
│                                                        │
│  3 TYPES     DEFENSIVE  they feel exposed              │
│              UNHEARD    volume is their last lever     │
│              TACTICAL   they're doing it on purpose    │
│                                                        │
│  DECODE      "Seems like something's going on here."   │
│              Safe on all three. Commits to no theory.  │
│              Aim slightly wrong. The correction is the │
│              diagnosis. Then STOP TALKING.             │
│                                                        │
│  DEFENSIVE   "That reaction makes complete sense       │
│               given what's on the line."               │
│              Give the exit. Don't take the ground.     │
│                                                        │
│  UNHEARD     "You're doing more processing here than   │
│               you're getting credit for."              │
│              Hand back the floor, visibly.             │
│                                                        │
│  TACTICAL    "It looks like there's nothing I can say  │
│               to change your mind."                    │
│              Name it, decline the fight, hold.         │
│                                                        │
│  SCORED      Label before any defense (binary) ·       │
│              type called correctly · one decode per    │
│              conversation, never two                   │
│                                                        │
│  FAILS WHEN  You decode, get the correction, then      │
│              argue with it. Attack two is always worse.│
│                                                        │
│  RECOVER     Take the loss on the factual point.       │
│              "Three weeks is three weeks." Being right │
│              is worth less than the deal.              │
└────────────────────────────────────────────────────────┘
```


## Part III · Steer


**Card 15 · The Calibrated Question**

```
┌─────────────────────────────────────────────────────────┐
│  THE CALIBRATED QUESTION             Part III · STEER   │
├─────────────────────────────────────────────────────────┤
│  Hand them the problem. They own answers they make.     │
│  Grammar: HOW and WHAT. Never WHY.                      │
│                                                         │
│  PUSHBACK    "How am I supposed to do that?"            │
│              "What would need to be true for this       │
│               to work?"                                 │
│              "What's making this harder than it         │
│               needs to be?"                             │
│                                                         │
│  CONSTRAINT  "What about this is most important to you?"│
│              "What's the one piece you're least         │
│               willing to bend on?"                      │
│              "How did you land on that number?"         │
│                                                         │
│  TOWARD YES  "What would need to happen for this to     │
│               be an easy yes?"                          │
│                                                         │
│  BUILD IT    "You need to…"  → "How am I supposed to…?" │
```

```
│              "that's right" on the GRIEVANCE            │
│                                                         │
│  FAILS WHEN  You solve at 90 seconds. Now the           │
│              settlement has to be bigger to pay for     │
│              the interruption.                          │
│  RECOVER     "I jumped in before you'd finished. Start  │
│              again from where it began. I won't         │
│              interrupt."   Then don't.                  │
└─────────────────────────────────────────────────────────┘
```


**Card 29 · Negotiating Internally: Up, Down, and Sideways**

```
┌────────────────────────────────────────────────────────┐
│  NEGOTIATING INTERNALLY         Part V · APPLICATIONS  │
├────────────────────────────────────────────────────────┤
│  You cannot walk away. No BATNA changes everything.    │
│  Optimize for the relationship. It produces every      │
│  future outcome.                                       │
│                                                        │
│  UP          Audit first:                              │
│              "You're probably thinking I'm asking      │
│               because my team is behind."              │
│              Then: "What am I not seeing from where    │
│               you sit?"                                │
│                                                        │
│  SIDEWAYS    No authority, no exit. Trade.             │
│              "If I take this on, what comes off        │
│               my plate?"                               │
│              "What's cheap for you that would be       │
│               expensive for me?"                       │
│              "It seems like you've been carrying more  │
│               of this than anyone's acknowledged."     │
│                                                        │
│  DOWN        The trap is authority. Don't use it.      │
│              "What's the part of this you disagree     │
│               with?"   ← presupposes it exists         │
│                                                        │
│  NEVER       Escalation as leverage. Works once,       │
│              remembered permanently.                   │
│              Winning in front of an audience.          │
│                                                        │
│  SCORED      Outcome AND relationship, separately ·    │
│              escalations near zero · peer asks paid    │
│              for · disagreement surfaced before        │
│              execution · audit used upward             │
│                                                        │
│  FAILS WHEN  You win the meeting. It reverses in two   │
│              weeks through channels you can't see.     │
│  RECOVER     "That went my way in the room and I don't │
│              think it landed well. What did I miss     │
│              about your side of it?"                   │
└────────────────────────────────────────────────────────┘
```


**Card 30 · When the Protocol Fails**

```
┌─────────────────────────────────────────────────────────┐
│  WHEN THE PROTOCOL FAILS        Part V · APPLICATIONS   │
├─────────────────────────────────────────────────────────┤
│  Three conditions defeat the method. Trying harder      │
│  makes all three worse.                                 │
│                                                         │
│  BAD FAITH   No intention of agreeing.                  │
│    TELL      Enthusiasm, no process detail. Nothing you │
│              concede produces movement.                 │
│    TEST      Ask for a small commitment. A next step    │
│              with a named attendee. They won't give it. │
│                                                         │
│  NO          They cannot agree, whatever they say.      │
│  AUTHORITY   Pronouns drift to "they." Everything is    │
│    TELL      provisional.                               │
│    TEST      Ask for a decision with a date. Authority  │
│              gives a mechanism; absence gives a feeling.│
│                                                         │
│  DEADLOCK    Both right, incompatible. Rarest.          │
│    TELL      Constraint is specific, consistent, and    │
│              external. Survives probing.                │
│    TEST      Probe it (Ch 19). Bracket it. If it holds, │
│              it's real. Say so out loud.                │
│                                                         │
│  END IT      "Sounds like that's a no."                 │
│              "It looks like there's real pressure on you│
│               to end this one way or another."          │
│              A third of the time it reopens honestly.   │
│                                                         │
│  BEFORE YOU  1 What if I negotiate? 2 What if I don't?  │
│  CONTINUE    3 Does this violate anything I hold?       │
│              4 Who else is affected?                    │
│                                                         │
│  SCORED      Diagnosis at 3 stalls · commitment test    │
│              run · time-to-kill tracked · clean endings │
│                                                         │
│  FAILS WHEN  You try harder. Sustained attention on     │
│              someone who can't be helped reads as       │
│              pressure however well executed.            │
│  RECOVER     "Is there a version of this that works     │
│              for you, or should I stop?"                │
└─────────────────────────────────────────────────────────┘
```

```
│  COMMIT      15 min Mon · 2 tapes Wed/Thu · 15 min Fri │

│                                                        │

│                                                        │

│                                                        │
```

**Card 32 · Coaching the Floor**

```
┌─────────────────────────────────────────────────────────┐
│  COACHING THE FLOOR            Part VI · INSTALLATION   │
├─────────────────────────────────────────────────────────┤
│  Diagnosis and rehearsal. Never demonstration.          │
│  Watching someone competent doesn't transfer the skill. │
│                                                         │
│  ORDER       1 THEIR read first, always                 │
│                "Where do you think it turned?"          │
│              2 ONE thing, behavioural, from tape        │
│                "Your talk time was sixty-eight percent."│
│              3 REHEARSE it now, in the room             │
│                "Run that thirty seconds again.          │
│                 I'll be them."                          │
│              4 ONE measurable commitment + a check day  │
│                                                         │
│  RESISTANCE  "It sounds like this feels like criticism  │
│               rather than coaching."                    │
│              "What's the part of this you disagree      │
│               with?"                                    │
│              Name the defence. Don't push through it.   │
│                                                         │
│  CONFIRM     Three ways or it isn't real:               │

│              right" → a how question. Wobbles on the    │

│                                                         │

│                                                         │
│  FAILS WHEN  You coach by demonstration. Score your own │
```
